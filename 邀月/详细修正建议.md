### 错误 1：第 35 行 - 郭盛名字错误

**原文**:
```
　　郭勝喚來下人送周大夫出府，自己幽幽地對月影兩人說道：
```

## 🟠 第二阶段修正（格式与简繁不统一）

### 错误 7：第 4 行 - 数字格式混用

**原文**:
```
　　公元７８１年，唐德宗建中二年暮春，一輛不起眼的尋常馬車，在長安街道上疾行。
```

**改正**:
```

```

**解释**:

## 🟡 第三阶段优化（表述优化）

### 建议 1：措辞提升

**位置**: 第 71 行（郭盛救田繻的场景）

**现有表述**:
```

```

## 🔧 修改建议（操作步骤）

### 方法一：使用编辑器的 Find & Replace

1. 打开 fullstory.txt
2. 快捷键：Ctrl+H 打开 Find & Replace
3. 逐个输入需要替换的内容
4. 使用 "Replace All" 或 "Replace" 逐个确认

### 方法二：使用脚本自动修改

如果您有多个文件需要批量修正，可以使用 Python 脚本：

```python
# 读取文件
with open('fullstory.txt', 'r', encoding='utf-8') as f:
    content = f.read()

# 修正列表
corrections = [
    ('郭勝', '郭盛'),
    ('郭慧連', '郭慧憐'),
    ('郭慧蓮', '郭慧憐'),
    ('田如', '田繻'),
    ('７８１', '781'),
    ('六岁', '六歲'),
]

# 应用所有修正
for old, new in corrections:
    content = content.replace(old, new)

# 写入文件
with open('fullstory.txt', 'w', encoding='utf-8') as f:
    f.write(content)

print("修正完成！")
```
