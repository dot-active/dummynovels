# 用本地 ComfyUI 一次性生成宣传视频的全部图片

`宣传视频脚本.md` 不能直接贴给 ComfyUI：ComfyUI 只认「工作流」，不认 Markdown，也不会自己把一份文档拆成二十几张图。

所以这里提供一个小工具 `comfyui_batch.py`。它会：
1. 直接读取 `宣传视频脚本.md`，自动找出每个镜头的 ` ```提示词``` ` 代码块（连同缩略图的提示词）；
2. 把每段提示词套进**你自己平常用的 ComfyUI 工作流**（不管用的是 SDXL、Flux 还是别的模型）；
3. 全部加入 ComfyUI 的队列，图片按镜头编号存好。

**不需要另外的提示词文件**，脚本每次都直接读 md；以后改了 md 里的提示词，重新运行一次就行。三本小说的脚本都能用。

---

## 第一步：准备（只做一次）

1. 电脑上装好 **Python 3**（ComfyUI 本身就需要 Python，一般已经有了）。不用安装任何额外的库。
2. 把整个 `dummynovels` 仓库拉到电脑上，或者只下载这两个文件：
   - `tools/comfyui_batch.py`
   - 你要的那本小说的 `宣传视频脚本.md`（例如 `邀月/宣传视频脚本.md`）

## 第二步：导出你的工作流（API 格式）

1. 启动 ComfyUI，打开你平常出图用的工作流（能正常生成一张图的那个）。
2. 建议先把它调好：
   - 用一个适合写实电影感的模型（SDXL 或 Flux 都可以）；
   - 采样步数、CFG 等设成你满意的值。
3. 导出 **API 格式**：
   - 新版界面：菜单 **Workflow → Export (API)**；
   - 旧版界面：先在设置里打开 **Enable Dev mode Options**，然后点 **Save (API Format)**。
4. 存成 `workflow_api.json`，和 `comfyui_batch.py` 放在一起最方便。

> ⚠️ 一定要是 **API 格式**。普通的「Save」导出的文件脚本用不了，会提示你重新导出。

**脚本会自动处理这些**，你不用改工作流：
- 正向提示词 → 换成每个镜头的提示词；
- 反向提示词 → 换成脚本 md 里写的那段反向提示词（不想改就加 `--no-negative`）；
- 图片尺寸 → 默认 **1344×768（16:9）**；
- 种子 → 每个镜头固定一个，同一个镜头重跑会得到同一张图；
- 保存位置 → `ComfyUI/output/小说名/镜头编号_00001_.png`。

如果脚本说「找不到正向提示词节点」（工作流比较复杂时会这样），在 ComfyUI 里把写正向提示词的那个节点**标题改成 `POSITIVE`**，反向的改成 `NEGATIVE`，再导出一次即可。

## 第三步：运行

打开终端（Windows 用「命令提示符」或 PowerShell），进入放文件的文件夹，运行：

```bash
# 先看看会生成哪些图（不会真的生成）
python comfyui_batch.py 邀月/宣传视频脚本.md --list

# 一次性把全部镜头加入队列
python comfyui_batch.py 邀月/宣传视频脚本.md workflow_api.json
```

运行完以后脚本就结束了，ComfyUI 会在后台按顺序一张张画。可以在 ComfyUI 的界面里看到队列进度。

## 常用选项

| 想做什么 | 命令 |
|---|---|
| 每个镜头多生成几张，挑最好的 | `--batch 4` |
| 只重新生成某几个镜头 | `--only 03,09,thumb` |
| 换一批完全不同的图 | `--seed 12345`（换任意数字） |
| 改尺寸（例如做 Shorts 的竖图） | `--width 768 --height 1344` |
| ComfyUI 不在本机默认地址 | `--server http://127.0.0.1:8188` |
| 保留工作流里自己的反向提示词 | `--no-negative` |
| 换输出文件夹名 | `--prefix 邀月_v2` |

例子：每个镜头生成 4 张候选

```bash
python comfyui_batch.py 邀月/宣传视频脚本.md workflow_api.json --batch 4
```

## 小提示

- **人物前后不一致**：ComfyUI 不像 Gemini 那样会「记得上一张图」。如果同一个角色在几张图里长相、衣服差别太大，可以：①多生成几张挑接近的（`--batch 4`）；②在工作流里加 IP-Adapter，用一张满意的图当参考；③反正脚本里人物大多是背影和远景，差别一般不明显。
- **出现文字或水印**：反向提示词里已经写了 text、watermark；还有的话，剪辑时裁掉或者换一张。
- **唐代服饰画成和服／清装**（邀月）：反向提示词里已经排除，仍然出现的话就多生成几张挑。
- **想先试效果**：先跑一张 `--only 01`，满意了再跑全部。
